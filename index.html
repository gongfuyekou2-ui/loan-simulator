📖 使い方
困ったらここ
📱 ホーム画面に追加（iPhone）
  1. Safariでこのページを開く
  2. 共有ボタン □↑ をタップ
  3. 「ホーム画面に追加」→「追加」
  4. 以後はアイコンから起動
☁️ 夫婦で同期する（無料）
  1. Supabaseで無料プロジェクトを作成
  2. 下のSQLをSQL Editorで実行（RLS設定込み）
  3. Authentication → Providers → Email で「Confirm email」をOFF（任意）
  4. Settings → API の URL と anon / publishable キー をコピー
  5. アプリの ☁️ で入力 → 新規登録 → 世帯を作成
  6. パートナーも登録し、「招待コード」で参加
⚠️ service_role / secret キーは絶対に入力しない（アプリが検知して拒否します）。無料枠は1週間アクセスがないと一時停止されることがあります（ダッシュボードで再開）。
